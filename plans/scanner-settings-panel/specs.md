# 扫码器功能重构与增强规范 (Specs) - v2

## 1. 核心架构调整
- **弃用 `Html5QrcodeScanner` (高层 UI 库)**：该库会自动向 DOM 注入不受控的按钮和状态机，在 React 的 `useEffect` 中极易产生竞态条件（导致 UI 重复）。
- **改用 `Html5Qrcode` (底层解码库)**：
    - **完全控制权**：由 React 组件负责按钮、预览框和状态切换的渲染。
    - **按需启停**：识别成功后立即调用 `.stop()`，释放摄像头资源，防止持续扫描。
    - **规避刷新**：通过 React 状态切换 UI，彻底取消 `window.location.reload()`。

## 2. 核心问题修复
- **重复 UI 根治**：由于不再使用 library 注入的 UI，重复现象将彻底消失。
- **循环加载修复**：移除了所有 `location.reload()` 调用，代之以 `startScanner()` 函数调用。
- **原生引擎优先**：设置项默认值改为 `native`。

## 3. 新功能实现：闪光灯 (Torch)
- **技术原理**：在扫码器启动成功后，通过底层 `Html5Qrcode` 实例获取当前的 `MediaStreamTrack`。
- **检查支持**：使用 `track.getCapabilities()` 检查是否支持 `torch` 属性。
- **状态控制**：使用 `track.applyConstraints({ advanced: [{ torch: true/false }] })`。

## 4. UI 交互逻辑 (用户审阅)
1. **初始态**：显示“开始扫描”按钮或直接尝试启动（根据权限记忆）。
2. **扫描态**：
    - 显示摄像头取景框。
    - 左上角/右上角显示“闪光灯”切换按钮（仅在设备支持时显示）。
    - 底部显示“停止”或“取消”按钮。
3. **成功态**：
    - 摄像头立即关闭（黑屏或显示定格画面）。
    - 弹出结果确认框（目前的样式已经很好）。
    - 提供“重新扫描”按钮，点击后再次进入“扫描态”，无需刷新页面。
