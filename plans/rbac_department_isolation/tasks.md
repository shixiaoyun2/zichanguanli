# 任务列表：RBAC 部门数据隔离与调拨审批流

- [ ] **基础架构与数据库变更** <!-- id: 0 -->
    - [ ] 扩展数据库结构：创建 `transfer_requests` 表用于存储调拨申请。
    - [ ] 修改 `users.departments` 处理逻辑：在注册和登录时确保存储的是 ID 字符串而非名称。
    - [ ] 强化 `auth.ts` 中间件，解析管辖部门 ID。

- [ ] **后端：核心路由与权限隔离** <!-- id: 1 -->
    - [ ] `GET /api/assets`：为 `operator` 角色强制注入 `dept_id` 过滤。
    - [ ] `GET /api/assets/:idOrCode`：
        - 属于管辖部门 -> 返回详情。
        - 不属于但存在 -> 返回 `limited: true` 和极简信息（用于发起调拨）。
        - 不存在 -> 返回 404。
    - [ ] `POST /api/assets`：操作员尝试新增资产时直接拦截并返回 403。
    - [ ] `GET /api/logs`：拦截操作员非法访问审计日志。

- [ ] **后端：调拨业务逻辑实现** <!-- id: 2 -->
    - [ ] 新增 `POST /api/transfers`：操作员提交调拨申请。
    - [ ] 新增 `GET /api/transfers`：管理员获取挂起的申请。
    - [ ] 新增 `PATCH /api/transfers/:id`：管理员审批。审批逻辑包含：更新资产表、记录调拨日志、关闭申请单。

- [ ] **前端：UI 交互优化** <!-- id: 3 -->
    - [ ] `AssetList.tsx`：隐藏按钮，过滤由于部门受限可能出现的“空数据”状态。
    - [ ] `Scan.tsx`：优化“跨部门资产”发现后的展示界面，增加“申请调拨”按钮及事由表单。
    - [ ] `Dashboard.tsx`：为管理员增加“待办申请”卡片提醒；为操作员增加管辖部门标签。
    - [ ] `Sidebar`: 动态显示菜单，非管理员移除“审计日志”、“人员管理”。

- [ ] **人员管理功能对齐** <!-- id: 4 -->
    - [ ] `PeopleManagement.tsx`: 修改设置部门的逻辑，确保选择的是 ID，并持久化 ID 字符串。
