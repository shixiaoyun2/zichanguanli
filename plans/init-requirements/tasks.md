# 资产盘点工具任务拆解 (Tasks)

- [ ] **任务 1：基础架构与数据库初始化**
    - [ ] 设计并执行 SQLite 建表语句 (Users, Assets, Organizations, Departments, InventoryLog)。
    - [ ] 配置服务器端目录：`/public/uploads` 用于存储资产图片。
    - [ ] 导出基础 `.env.example`，包含 `GEMINI_API_BASEURL` 等可配置项。

- [ ] **任务 2：多角色身份验证系统**
    - [ ] 后端 Express 加密存储用户密码，实现 JWT/Session 权限模型。
    - [ ] 前端实现 `AuthContext`：全局管理角色信息。
    - [ ] 定义权限中间件：拦截普通操作员对 `POST /api/assets` (新建) 和 `DELETE` 接口的请求。

- [ ] **任务 3：核心管理 API 开发**
    - [ ] 实现资产增删改查：处理多表关联（Organization/Department ID 与 Name 的转换）。
    - [ ] 实现图片上传：支持 Multer，自动处理 `[资产组织]-[资产编码]-[日期].jpg` 命名规范。
    - [ ] 实现图片联动重命名：当编码或组织变更时，同步修改文件名。
    - [ ] 资产状态变更与审计日志：任何修改必须检查 `updated_at` 是否冲突，并记录 `before/after` 快照到 `InventoryLog`。
    - [ ] **实现回滚 API**：允许管理员根据日志 ID 恢复资产数据。

- [ ] **任务 4：响应式 UI 与资产展现**
    - [ ] 实现资产列表页：
        - 窗口宽度检测：移动端渲染 `Card` 组件，桌面端渲染 `Table` 组件。
        - 搜索与高级过滤（部门/状态）。
    - [ ] 实现资产详情/编辑页：集成多字段表单。
    - [ ] **实现审计日志管理页 (限Admin)**：
        - 列表展示历史变更记录。
        - **实现 Diff 差异对比组件**：高亮显示修改点（如红色代表旧值，绿色代表新值）。
        - 提供“回滚到此版本”功能按钮。

- [ ] **任务 5：高级扫码与图片采集**
    - [ ] 前端扫码逻辑：集成 `html5-qrcode`。
    - [ ] 扫码结果路由：匹配资产 ID -> 打开详情页；匹配失败 -> 处理对话框（修改/退出/新增(限Admin)）。
    - [ ] 图片采集：支持调用摄像头或从相册选择，实时预览并上传。

- [ ] **任务 6：复杂 Excel 导入导出**
    - [ ] 实现导出：一键将所有资产（含关联表名称）导出。
    - [ ] 实现导入逻辑：
        - 预处理：静默创建不存在的组织/部门。
        - 冲突算法：对比差异、提示并处理手动合并逻辑。

- [ ] **任务 7：AI OCR 增强对接**
    - [ ] 后端中转 API：封装对 Gemini API 的调用，保护密钥。
    - [ ] 前端实现“AI 填充”开关。
    - [ ] 处理 OCR 结果映射：将 AI 返回的非结构化文本映射至表单字段。

- [ ] **任务 8：性能优化与联调**
    - [ ] 实现前端 `localStorage` 影子数据（离线查看快照）。
    - [ ] 实现编辑提交时的版本校验逻辑（Optimistic UI/Locking）。
    - [ ] 模拟真实多角色账户交互路径测试。
