# 人员管理与图片导出设计规范 (Specs)

## 1. 界面汉化 (UI Localization)
- **扫码组件汉化**：
  - 通过 `html5-qrcode` 的渲染后 DOM 注入实现：
    - "Request Camera Permissions" -> "请求摄像头权限"
    - "Scan an Image File" -> "浏览本地图片"
    - "Stop Scanning" -> "停止扫描"
- **按钮与提示语**：全量检查并替换为中文。

## 2. 人员管理功能 (People Management)
- **权限边界与属性**：
  - 仅 `admin` 可访问。
  - 支持用户增删改查。
  - **多部门绑定**：管理员在创建/编辑用户时，可以为该用户指定一个或多个“所属管理部门”。
  - 禁止删除当前登录账号。

## 3. 图片批量打包导出 (Image Bulk Export)
- **严格限制**：**仅限管理员 (Admin) 发起**。操作员 (Operator) 无法看到下载按钮，后端 API 将强制校验请求者身份。
- **技术实现**：后端通过 `archiver` 完成 `public/uploads` 目录的打包，文件名含时间戳。

## 4. 资产编辑权限 (Asset Editing)
- **部门锁定逻辑**：操作员 (Operator) 只能核对与完善**其管辖范围内**（Asset.dept_name 属于 User.departments 列表）的资产信息。
- **编辑范围**：
  - 若部门匹配，允许修改：管理部门、使用人、资产状态、重新上传照片。
  - 若部门不匹配，仅允许“查看”，编辑操作将被锁定并在界面给予提示。
- **管理员权限**：不受部门锁定限制，可编辑任意资产。

## 4. UI 交互优化
- **差异视图增强**：在审计日志的回滚预览中，增加更直观的字段图标。
- **表单校验**：增加中文提示语的表单校验逻辑。
