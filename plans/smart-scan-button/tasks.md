# 智能扫码按钮实现任务清单

- [ ] **任务 1：定义按钮状态组件逻辑**
  - [ ] 在 `ScanPage` 中识别三种核心交互状态。
  - [ ] 编写一个计算函数或变量，根据 `isScanning`, `scanResult`, `error` 确定当前的按钮配置（文字和 Action）。

- [ ] **任务 2：重构底部按钮 UI**
  - [ ] 找到 `Scan.tsx` 中的“重新扫描”按钮代码块。
  - [ ] 将其修改为动态渲染，支持文字切换。
  - [ ] 确保点击事件动态绑定到 `startScanner` 或 `stopScanner`。

- [ ] **任务 3：优化“停止”与“重新启动”的过渡**
  - [ ] 确保点击“停止扫码”时，UI 能立即响应，取景框出现遮罩或加载状态。
  - [ ] 验证 `isTransitioning` 锁机制在频繁点击下的稳定性。

- [ ] **任务 4：细节调优**
  - [ ] 配合 `motion` 实现平滑的文字淡入淡出。
  - [ ] 处理边缘情况：如果在 `notFound` 弹窗显示时点击了底部按钮，应确保能正确处理状态（通常弹窗会屏蔽底部操作，或者同步关闭弹窗）。
