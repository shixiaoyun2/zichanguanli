# 智能扫码按钮 (Smart Scan Button) 设计规范

## 1. 功能目标
将现有的单一“重新扫描”按钮替换为状态敏感的“智能交互按钮”，根据扫码器的当前状态动态调整显示文字与点击行为，优化用户交互链路。

## 2. 状态机逻辑定义

| 状态描述 | 判定条件 | 按钮文字 | 点击动作 |
| :--- | :--- | :--- | :--- |
| **扫码进行中** | `isScanning === true` | 停止扫码 | 调用 `stopScanner()` |
| **就绪/空闲** | `isScanning === false && !scanResult && !error` | 开始扫码 | 调用 `startScanner()` |
| **识别成功** | `scanResult !== null` | 重新扫描 | 清除结果并调用 `startScanner()` |
| **发生错误** | `error !== null` | 重新扫描 | 清除错误并调用 `startScanner()` |

## 3. UI 表现
- **样式**：保持现有的 Indigo 圆角长按钮样式。
- **动效**：当状态切换时，推荐使用 `AnimatePresence` 处理文字切换，避免生硬跳变。
- **位置**：维持在取景框下方中心位置。

## 4. 辅助交互
- 如果扫码成功后弹出了“未找到资产”弹窗，底部的按钮应配合状态显示。
- 按钮进入“停止扫码”状态时，可以考虑改变背景色（如变为浅灰色或红色）以增强视觉引导，但初步建议先保持品牌色 indigo 观察效果。
